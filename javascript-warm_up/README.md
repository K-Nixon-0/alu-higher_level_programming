# JavaScript Warm Up

This folder contains beginner JavaScript exercises focused on core syntax and basic programming concepts. The goal is to practice variables, string handling, command-line arguments, loops, functions, arrays, objects, and recursion before moving on to more advanced JavaScript projects.

## Files in this folder

- `0-javascript_is_amazing.js` — defines a variable and prints: `Javascript is amazing`.
- `1-multi_languages.js` — prints multiple strings in sequence.
- `2-arguments.js` — prints how many arguments were passed to the script.
- ` 3-value_argument.js` — prints the first argument passed to the script, or a default message if no argument is given. Note: this file name starts with a leading space.
- `4-concat.js` — concatenates two arguments into a single output string.
- `5-to_integer.js` — converts an argument to an integer and prints it, or reports that it is not a number.
- `6-multi_languages_loop.js` — uses a loop to print the same language examples repeatedly.
- `7-multi_c.js` — exercises loops and repeated output patterns with the letter `C`.
- `8-square.js` — prints a square made from a character provided as an argument.
- `9-add.js` — adds two numbers passed in as arguments.
- `10-factorial.js` — calculates the factorial of a number using JavaScript.
- `11-second_biggest.js` — finds the second-largest integer from the provided arguments.
- `12-object.js` — modifies or updates a JavaScript object.
- `13-add.js` — adds functionality related to object/module-based arithmetic practice.
- `README.md` — this documentation file describing the contents of the folder.

## Notes

Most of the exercise files in this folder are intended as coding tasks and may currently be empty stubs waiting to be implemented. The project is a warm-up to build confidence with JavaScript fundamentals.
